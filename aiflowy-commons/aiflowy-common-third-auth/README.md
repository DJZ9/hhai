# aiflowy-common-third-auth

## 模块定位

第三方认证公共模块，封装微信、钉钉等平台的 OAuth、用户信息和回调处理基础能力。

## 主要职责

- 生成授权地址和 state。
- 处理回调 code、Token 和第三方用户标识。
- 为认证模块提供统一的第三方身份抽象。

## 安全注意

回调地址必须使用正式域名，校验 state、防重放和平台签名；AppSecret 等密钥不能写入前端或提交到日志。
## OAuth 链路

前端请求授权地址 -> 服务端生成并保存 state -> 第三方回调 code -> 服务端换取 access token 和 openid / unionid -> 绑定或创建系统账户 -> Sa-Token 登录。

## 扩展平台

新增平台时应实现授权地址、回调参数、用户信息映射和异常处理，并把 provider 配置放入服务端。回调接口需要校验 state、重放、来源域名和账户绑定冲突。
